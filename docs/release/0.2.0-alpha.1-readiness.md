# Playtestr 0.2.0-alpha.1 readiness evidence

Date: 2026-08-19

Status: local release candidate; not tagged or published.

## Implemented scope

- equal-cap benchmark containing intelligent autonomy, coverage-guided, round-robin, and
  seeded-random strategies;
- twelve-scenario classified terminal gauntlet;
- revisioned compatible campaign persistence and world-model hydration;
- exact-signature finding registry and optional fresh-process reproduction quorum;
- canonical JSON, escaped standalone HTML, Markdown, and replay evidence reports;
- restrictive, redacted Docker execution planning and daemon capability probe;
- bounded provider-neutral supervisor agent;
- backend-neutral graphical contracts and deterministic in-memory episode conformance;
- AGPL-3.0 metadata and complete license text;
- release-candidate version `0.2.0-alpha.1`, still `private: true`.

## Local evidence

- `npm run check`: 26 test files and 53 tests passed; typecheck and production build passed.
- Full gauntlet: 12/12 scenarios passed in 453.5 seconds with zero cleanup failures.
- Fixed-seed discovery comparisons: autonomy was `competitive` in 10/10 runs, used the
  complete executable action cap, and had zero cleanup failures.
- Current result does not prove dominance over coverage-guided exploration; both reached the
  best evidence score in the committed matrix.
- Campaign smoke: revision advanced from 1 to 2; sessions, episodes, actions, world states,
  and report artifacts survived reload.
- Finding smoke: intentional crash deduplicated to one signature and reproduced stably in 2/2
  fresh attempts.
- Lifecycle soak: 100/100 clean runs; no remaining native handles.
- Docker plan smoke: local daemon reachable; plan only, no target container executed.
- npm advisory audit: zero vulnerabilities after the patched esbuild override.
- npm package dry-run: 12 files, 130,916 bytes packed, 559,338 bytes unpacked.
- Installed-tarball smoke: clean consumer installation; 65 exports loaded and all nine new
  product APIs were present.
- Gamr bridge: three real episodes, six actions, two states, `dispatch-briefing` milestone,
  and confirmed clean lifecycle.

## Remaining release gates

- Remote Node 22 Windows/Linux/macOS and Node 24 Linux CI must pass for the pushed commit.
- Remote Windows lifecycle soak must pass.
- Repository owner must explicitly accept AGPL-3.0 obligations for Playtestr.
- npm trusted publisher/OIDC and provenance must be configured.
- `private` must remain true until the publication review.
- No tag or npm publication is authorized by this evidence document.
- Docker target execution requires Replay V2 backend identity and forced-removal tests.
- Browser execution requires a pinned runtime, explicit browser installation, local-origin
  threat review, and platform-specific visual-baseline policy.
- Agent work should next target measurable dominance on held-out games rather than increasing
  claims or provider complexity.
