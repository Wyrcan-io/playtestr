# Playtestr v0.3.0-rc.1 release notes

Published 18 September 2026 from commit
`7cf64afc105decfdbbe37141d45ab5b15e32c3d6`.

Sprint 7 adds one command for understanding captured failures without a server,
account, network connection, target rerun, or test-spec reread:

```text
playtestr report --input artifacts/results.json --evidence-root artifacts --output artifacts/report.html
```

The generated HTML is a bounded, atomic, self-contained file with failure-first
navigation, the recorded failing step and category, viewport, captured screen,
unified diff, and separate target, cleanup, and evidence-write outcomes. It is
responsive, keyboard accessible, readable without JavaScript, and contains no
remote assets or telemetry.

The renderer rejects unsafe or inconsistent evidence references, including
traversal, absolute and network paths, URIs, escaping links and junctions,
hard-linked/shared evidence, and input/evidence output aliases. Missing optional
evidence remains visibly labeled. Report v1 and specification v1 are unchanged;
the renderer does not invent omitted expected strings, input, history, or root
causes.

Relative to stable `v0.1.0`, the prerelease also includes deterministic
recursive suite discovery, `test --list`, aggregate suite outcomes, isolated
artifact directories, and the static documentation website. See
[`CHANGELOG.md`](../../CHANGELOG.md) for the complete user-visible delta.
