# Bounded Unix terminal startup replies

Status: implementation prepared; native Linux regression pending.

The Git Town controlling-terminal probe on run `41881662967` captured only
`OSC 11;?` and `CSI 6 n` before timing out. The same binary completed with
visible output when launched on a PTY without a controlling terminal. This
isolates the earlier blank-screen failures to startup queries that the terminal
emulator already understood but the Unix session bridge discarded.

Forward only responses generated by vt10x for primary device attributes,
device-status reports, cursor-position reports, and default foreground and
background color queries. Validate the exact response shape before queueing.
Keep the existing 16 KiB per-session response cap, bounded queue, dedicated
writer, shared input serialization, and cleanup behavior. Windows continues to
rely on ConPTY. Other device and OSC queries remain unsupported. Do not alter
timeouts or add a Git Town-specific environment workaround.

The focused regression drives repeated mixed queries and normal input through a
real Unix PTY, verifies response order and bytes, checks that unsupported or
malformed response shapes are discarded, and retains the existing flood and
blocked-writer cleanup tests. The Git Town Linux workflow runs these tests before
its frozen 20-case development series. A successful source test and Git Town
development run will not qualify private archives or another project; the later
candidate and prior-project gates remain separate.
