Status: frozen for exact-candidate qualification, no admission credit. The source pin is `a2df95f26762fc3e78d6f131cea7fc1f3b13bd47` (Taskell 1.11.4). The machine-readable contracts and copied fixture tree are in `host-contracts/`; their content hashes are in `scenarios.json`. The catalog contains 8 normal workflows (N01?N08), 12 semantic edge families (E01?E12), and 21 actual invocation contracts because malformed E11 and its fresh-workspace recovery are separate runs. Every contract uses the exact authored v3 spec and fixture bytes from `first-use-v1`, with only fixture paths rebased to the frozen sibling tree. All twenty candidates passed once on Ubuntu 24.04 x86-64 and Intel macOS 15 in run `42489015452`; the existing-task N01 smoke passed on both hosts in the same run. The one-shot packet and report hashes remain bound in `build-attempt-v32.json`. This validates scenario feasibility, not repetitions, Apple Silicon behavior, exact-candidate final behavior, fault calibration or admission.

N06 and N08 state-byte expectations include the serializer's required inter-list separator. E12 expects exact exit 1 after the genuine read-only save rejection and verifies the original board bytes. E11 malformed input and recovery remain separately identified. All cases require positive terminal evidence, their exact saved/absent state, and confirmed process and workspace cleanup. The catalog binds source spec hashes, transformed-series spec hashes, fixture files, the source pin and the cross-host exploratory packet.

The final series uses 12 batches on standard GitHub-hosted Ubuntu 24.04 x86-64 and macOS 15 arm64, 21 cases per batch per host (504 ordinary invocations total), and three source faults with baseline/mutated/restored phases on each host (18 calibration invocations). No per-case retry is allowed. A failed batch is retained and rejected; any replacement receives a new declaration. Candidate bytes must match the private frozen rc.6 archives exactly.

Risk pairs are E03 with N06 (ambiguous duplicate labels plus column movement), E05 with N05 (resize/redraw plus reorder), E07 with N02 (Unicode/spaced path plus task creation), E06 with N01 (off-screen completion), E01 with E04 (blank input and Escape edit behavior), and E09 with N06 (immediate persistence after movement). Combinations remain bounded in their individual fixtures; this does not claim a full Cartesian matrix.

The three source fault candidates are (1) remove the completion reducer's move-to-Done transition, (2) make `q` fail to transition to shutdown, and (3) serialize no task rows while leaving the terminal transition intact. Each will be evaluated against the unchanged reviewed contract, with source and binary hashes for pristine, mutated and restored phases. Until those native fault phases and the exact-candidate series pass, Taskell remains unadmitted.
