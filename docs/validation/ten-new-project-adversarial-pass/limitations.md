# What this evidence does and does not establish

The final audit, when successful, qualifies the pinned applications, reviewed
contracts, declared environment policies and exact native-host runner identities
in its report. Ten repetitions check stability of those cases; they do not
estimate a percentage of possible user behavior. Synthetic fixtures deliberately
avoid real credentials, home-directory scans and production data.

- A passing terminal screen does not prove filesystem correctness. Real source
  corruptions demonstrate that limitation. Independent campaign probes check
  exact declared file bytes, absence and directory state in separate recorder
  executions; they are not a shipped public filesystem assertion feature and
  cannot prove the state of every ordinary test execution.
- Historical failures stay failures. The first frozen campaign failed Copier's
  Windows Git-update preparation checkpoint. Its separately measured,
  Windows-only 20-second authoring budget preserves all assertions and snapshots.
  Later qualification does not turn that first campaign into a pass.
- One macOS race-instrumented stubborn-descendant test failed readiness while
  cleanup was confirmed. Its cause remains unconfirmed. Subsequent successful
  native suites and fifty additional repetitions provide bounded evidence,
  without proving a causal production fix. Improved failure diagnostics remain
  available. See [the investigation](core/macos-stubborn-investigation.json).
- The earliest historical Windows wizard timeout has no proven internal OS
  diagnosis. Later reproducible resize problems received general repairs and
  retained before/after evidence; successful historical-sequence repetitions
  do not establish the cause of every old failure.
- Superfile and Glow on Windows remain unqualified after actual pinned-upstream
  input-race findings. Native execution on another OS, cross-compilation, or
  Yazi's successful Windows matrix does not qualify those paths.
- Terminal styling, arbitrary grapheme/width behavior, mouse interactions,
  clipboard/editor/plugin integrations, external services, filesystem ownership
  semantics and arbitrary workload timing are covered only where a specific
  retained contract says so. The selected workflows are not complete application
  test suites.
- The runner executes trusted applications with the user's permissions. A PTY,
  subprocess or owned temporary directory is not a security sandbox. The
  confidentiality controls have explicit evidence boundaries; a target can
  deliberately print secrets into its screen.
- First-use routes have prepared fixtures, prior operator knowledge and warm
  caches. Eight timings are automated walkthrough elapsed time, not measured
  human authoring time. See [the usability assessment](usability-assessment.md).
  This is not independent beginner research, adoption evidence or proof of
  automatic test/spec discovery.
- Native Actions jobs are hosted execution of the retained commands. This pass
  does not add a new real pull-request, paid-app, billing, tenant, production
  operations, release or customer-payment validation journey.
- Stored evidence inventories measure checkpoints, not peak resource usage or
  operating-system quotas. Downloaded archives duplicate historical ledgers and
  identity metadata; their whole expanded sizes differ from each project's
  measured raw execution-evidence budget. Hashes preserve integrity but do not
  keep remote artifacts available after expiry.

- A later macOS helper exit8 exposed a proven test-fixture heartbeat publication race in a reduced checkpoint. Atomic replacement passed that regression, native normal/race checks, fifty macOS cleanup repetitions and renewed all-ten qualification. The exact original hosted exit8 branch was not logged, so its causal trace remains limited. Production Go inputs and product deadlines did not change. [Failure, repair and limits](core/macos-stubborn-late-failure/manifest.json).

The standalone runner remains deterministic and AI-free. The paid integration
and buyer lifecycle remain future work. This pass earns no complete-product
100-project launch credit and does not authorize marketing, outreach or release.
