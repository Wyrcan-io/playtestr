# superfile scope declared before acquisition

Pinned MIT Go/Bubble Tea v2 application: [yorukot/superfile](https://github.com/yorukot/superfile/tree/66fe169b87021f7424522ed5aadd711c5676601e). Linux and Windows remain provisional. Source/runtime acquisition must wait for lf's native qualification and verified local deletion.

The pinned [configuration](https://github.com/yorukot/superfile/blob/66fe169b87021f7424522ed5aadd711c5676601e/src/superfile_config/config.toml) and [hotkeys](https://github.com/yorukot/superfile/blob/66fe169b87021f7424522ed5aadd711c5676601e/src/superfile_config/hotkeys.toml) document creation/rename prompts, Ctrl+C/Ctrl+X/Ctrl+V file operations, new/split panels, selection mode, search, sort, hidden files and confirmation cancellation. The source requires Go 1.26; the target build recipe explicitly selects reviewed Go 1.27.0, independent of Playtestr's Go 1.25 minimum. Configure automatic update checks off, Nerd Font/image/metadata/external integrations off, and exclude host-dependent metadata using explicitly reviewed semantic regions. Start from task-owned synthetic state and temporary home/data; never invoke an external editor/opener on user files.

| ID | Useful workflow or distinct risk | Required terminal and independent evidence |
| --- | --- | --- |
| normal-search-preview | Search a noninitial item in a nested directory and inspect preview | Correct selected caption and unique actual file content; original bytes retained |
| normal-create-state | Create a named directory/file through the actual creation prompt and navigate to it | Confirmed new state, exact generated bytes or intentionally empty file, protected neighbor unchanged |
| normal-project | Rename a real file to a spaced Unicode name | Fresh selected/result caption, exact renamed bytes, original path absent |
| normal-panel-copy | Use separate panels to copy between different directories | Distinct source/destination panel evidence and exact copied bytes |
| normal-panel-move | Cut/paste into another panel's directory | Exact destination, original absent, protected state unchanged |
| normal-multiple-selection | Select nonadjacent items and perform a real batch operation | Correct target item set; independent exact contents and untouched unselected neighbor |
| edge-empty-recovery | Enter an empty directory and recover to useful state | Genuine empty current state rather than an old preview; explicit recovered selection |
| edge-no-match-recovery | Search a missing item and recover without restarting | Actual no-result state then genuine selected item; files unchanged |
| edge-cancel-edited-rename | Cancel a rename after editing | Observed prompt disappearance, original bytes/path, proposed name absent |
| edge-cancel-delete | Begin a destructive confirmation then decline | Confirmation transition, selected file and neighbor preserved |
| edge-name-conflict | Attempt an occupied destination and refuse replacement or observe supported rejection | Both different original contents remain; no silent overwrite counted as success |
| edge-resize-scroll | Resize repeatedly around long lists and Unicode content, then select a previously offscreen item | Fresh semantic selected/preview evidence after resize; exact original state |

These intentions are provisional until actual pinned source and execution establish precise keys, captions and supported behaviors. Replace unsuitable intentions with equally substantive risks and explain the exclusion before authoring their contracts. Do not infer readiness from a command being typed or a highlight alone.

Use ten-second steps, 120-second cases, two-MiB terminal output, bounded tiny fixtures, four-GiB owned application/cache budget and 128-MiB raw application evidence. Terminal snapshots and independent current-workspace state checks are separate executions/counts. Source/license/dependency identities, two different genuine source faults, saved-state false-green rejection, exact restoration, meaningful suffix rerecord, manual edit, reviewed named baseline maintenance, relocation, workflow-equivalent commands, native Linux/Windows repetitions and verified source/cache deletion remain mandatory.

Archive formats, shell/editor/opener integrations, image protocols, external metadata tools, operating-system clipboard providers and privileged filesystem behavior are excluded from this initial scope. No claim of complete superfile feature coverage, compatibility or accepted project credit is made.
