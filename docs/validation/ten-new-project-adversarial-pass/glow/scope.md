review of its pinned README, module requirements and list/pager implementation.

provisional hosts; every claimed host needs actual successful execution.

documents, an isolated temporary home and explicit fixed rendering settings.

pagers or real user repositories. Go 1.27.0 and exclusively owned build/module
caches are the reviewed build route for the pinned Go 1.26.7 requirement.
