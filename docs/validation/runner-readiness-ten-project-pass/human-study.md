# Prepared unfamiliar-participant study

Status: materials prepared, zero participants observed; no recruitment authorized.
Do not assign agent measurements to these records or claim beginner readiness.

Before use, obtain voluntary consent to record commands, errors, assistance and
active task intervals using synthetic data. Permit withdrawal and omit personal
information from shared evidence. Record self-described command-line experience
as none, occasional, regular or expert; do not infer it from performance.

Five participant slots should span differing technical experience. Each receives
the same exact candidate archive, public docs and a trusted installed synthetic
target. Target preparation and Playtestr installation are timed separately.

Task 1: verify/install the candidate, record a meaningful change, choose a screen
and saved-file expectation, inspect the candidate, replay and export a passing
ordinary test. No prepared Playtestr spec or handwritten JSON is supplied.
Engineering count targets: five invocations and twenty controls. Proposed human
target: fifteen active minutes after the target is available.

Task 2: run a preseeded target regression preserving its success screen. Identify
the failed step, saved-state category and useful next action from ordinary
machine/HTML evidence. Allow three documented diagnostic shell commands; proposed
human target ten active minutes. Never tell participants which expectation failed.

Task 3: review one intentional file change, update only that state expectation,
replay and run normally; verify unrelated screen/file expectations remain intact.
Move the package into an owned spaced/Unicode directory and rerun. Generate the
free workflow and explain its target-build prerequisite without publishing it.

Observation form (one per participant): candidate/archive/binary hashes; target
pin/runtime/fixture; experience band; start/end and paused intervals per task;
every shell invocation/recorder control/target interaction; documentation jumps;
all errors, assistance and abandoned routes; resulting spec/baseline hashes;
success/failure criteria actually observed; cleanup and optional feedback.

Record raw intervals before calculating active duration. Stop the task when the
participant requests it; retain incomplete outcomes. A five-person formative
sample cannot establish population reliability or conversion/adoption.
