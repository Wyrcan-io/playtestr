# Repository skill catalog

Planned local workflows:

- `terminal-target-authoring`: create safe deterministic fixture games and manifests.
- `playtest-investigation`: reproduce, minimize, and package a finding.
- `adapter-authoring`: add optional semantic state/events without coupling core to a game.
- `release-verification`: run typecheck, tests, build, replay smoke tests, and artifact checks.

These workflows should be added as focused instructions only when their acceptance checks are clear. They must not grant an agent permission to run arbitrary target commands without the target sandbox policy.
