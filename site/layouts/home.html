01 / THE CONTRACT

A small test connects input, screen state, and evidence.

1

Start a trusted application

Choose a command and viewport. Playtestr opens a real pseudoterminal and keeps execution inside explicit time and output limits.

2

Describe the keyboard flow

Wait for visible text, send keys or text, resize when needed, and assert the exact exit status for finite commands.

3

Review what changed

Assertions inspect rendered text after cursor movement and redraws. Snapshot mismatches produce a diff, screen evidence, and nonzero runner exit.

02 / A USEFUL FAILURE

See the difference.
Keep the evidence.

A changed screen produces a bounded text diff and a nonzero exit code. The captured screen and diff identify the failed spec without turning terminal output into a hosted service.

Inspect the reproducible example →

Bounded runs

Step deadlines, a total timeout, output limits, cancellation, and managed process cleanup keep failures finite.

Rendered assertions

Checks inspect visible terminal text after cursor movement, alternate-screen use, redraws, and supported viewport resizing.

Deliberate baselines

Snapshot changes are reviewed and selected explicitly. Updates commit only after the spec and cleanup succeed.
