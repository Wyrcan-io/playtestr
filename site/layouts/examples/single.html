Run the examples locally

The website controls explore prepared, sanitized states. The browser does not run a pseudoterminal. To execute the same repository fixtures, build the current source checkout and run:

go build -o bin/demo ./cmd/demo
go run ./cmd/playtestr test examples/menu.json
go run ./cmd/playtestr test examples/snapshot-mismatch.json

The first command should pass. The snapshot-mismatch command is deliberately expected to exit 1 and write its actual screen and diff. On Windows, add .exe to the demo output name.
